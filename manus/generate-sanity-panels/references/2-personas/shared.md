# Personas — shared

Stage 2. In: `definitionBundle`. Out: `personas.json`

## Process

- **3–6 personas** from `{brief}` + `domainSnapshot.tone` (prefer comprehensive over aggressive merge)
- Each: `title`, `description`, `jtbd`, `successCriteria`
- Keep **distinct JTBD** — do not fold gift into personal shopper, or bulk/institutional into local church buyer
- Note MoFu vs BoFu drivers in `description` for stage 5
- Tie to `{brief}` — no generic filler personas
- Gate may expand or trim; default to the target’s full palette when it fits the brief

```json
{
  "personas": [
    { "title": "...", "description": "...", "jtbd": "...", "successCriteria": "..." }
  ]
}
```

Gate: user approves persona set or edits.
