# Product page spine

Brief-agnostic default sequence. Adapt per `{brief}`.

1. Hero — product proof or thematic opener
2. Value blocks — 3–5 sections (maker spotlight, themes/topics, social proof; specs only if not already on live PDP chrome)
3. Commerce blocks — related products (select with stock awareness; **do not render** price/stock/dispatch in panel copy), comparison, CTA
4. Trust close — FAQ or guarantee
5. Final CTA

**Maker** = author (books/Bibles/media) or manufacturer/brand (candles, instruments, gifts, etc.). Adapt labels to product type.

No fixed panel `_type`s here. Content stages name sections only. **Content strip only** — do not duplicate live PDP chrome (title, price, buy box, core specs table).
